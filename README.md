# Plant Breeding Mini Project (RStudio)

This beginner-level project explores basic statistical analysis in a plant breeding dataset using R.

## Objective
To analyze the relationship between plant traits (height, disease score, variety) and yield using:
- Pearson correlation
- Linear regression (`lm()`)
- Data filtering and visualization with `dplyr` and base R

## Dataset
A small-scale dataset containing:
- Plant height (cm)
- Disease score (1–9 scale)
- Variety categories (V1–V4)
- Yield (kg/ha)

## Skills Practiced
- Data import and cleaning
- Correlation analysis with `cor()` and `cor.test()`
- Linear modeling with `lm()`
- Interpretation of model output (coefficients, p-values)
- Use of `%>%` pipe and tidyverse functions
